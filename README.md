# Pelispanda — plugin para Kino TV

Plugin no oficial para [Kino TV](https://kinotvapp.github.io/kino-plugins/) que lista y
reproduce el catálogo de **pelispanda.org** (películas, series y animes) en línea.

## Cómo instalar

En Kino: **Ajustes ▸ Plugins**, pegá la dirección y tocá **Agregar**:

```
baskettv23/Pelispanda
```

o el enlace directo:

```
https://raw.githubusercontent.com/baskettv23/Pelispanda/main/kino-plugin.json
```

Requisitos: **Kino 0.9.50 o superior** (`apiVersion` 6) y conexión a internet.

## Qué hace

- **Inicio**: Destacadas, Películas, Series, Animes, Estrenos y filas por género/idioma.
- **Búsqueda** y navegación paginada.
- **Capítulos** de series y animes.
- **Reproducción** de los servidores del sitio (Latino/Castellano/Subtitulado), con las
  demás copias disponibles como "Servidor" alternativo.

No usa cuentas, contraseñas ni ajustes: se instala y funciona.

## Cómo pedir una actualización

Kino busca actualizaciones solo (cada 12 h) o cuando tocás **Buscar actualización** en la
fila del plugin.

## Aviso

Proyecto comunitario sin relación con Kino ni con el sitio de origen. El contenido lo
publica el sitio de origen; este plugin solo lo indexa.
